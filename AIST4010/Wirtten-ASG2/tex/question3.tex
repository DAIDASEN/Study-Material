\textbf{Symptoms.} Loss plateaus or oscillates in early epochs without downward trend.

\textbf{Likely causes (examples).}
\begin{itemize}[leftmargin=*]
  \item \emph{Learning rate mis-specified}: too low (minuscule updates) or too high (overshooting/oscillation). Consider LR range test or scheduler warmup.
  \item \emph{Data/label issues}: missing normalization/standardization; severe label noise or class leakage; erroneous preprocessing/augmentations.
  \item \emph{Initialization/activation mismatch}: poor initialization (symmetry, saturation), incompatible with activation (e.g., sigmoid + large weights).
  \item \emph{Optimization setup}: wrong loss (e.g., missing reduction/weights), disabled gradient flow (requires\_grad/ detach), weight decay too large; model accidentally in eval mode (BatchNorm/Dropout frozen).
  \item \emph{Batching/runtime}: batch size too small/large; exploding gradients with silent NaNs (check gradient norms, enable anomaly detection).
\end{itemize}
