### CPR: Cumulative Process Reward

原始目标函数:
$$\max_{\pi} \mathbb{E}_{s_0 \sim \rho(s_0), a_t \sim \pi(a_t | s_t)} \left[ \sum_{t=0}^{T} \left( r(s_t, a_t) + \beta \log \pi_{\text{ref}}(a_t | s_t) \right) + \beta \mathcal{H}(\pi) \right]$$
存在最优策略公式$\pi^*(a_t | s_t) = \frac{e^{Q^*(s_t, a_t) - V^*(s_t)}}{\beta}$以及最优值函数$V^*(s_t) = \beta \log \sum_{a \in A} e^{Q^*(s_t, a_t) / \beta}$
和我们之前一样能够得到原始的Q函数:
$Q^*(s_t, a_t) = r(s_t, a_t) + \beta \log \pi_{\text{ref}}(a_t | s_t) + V^*(s_{t+1})$
此外还有Bellman方程: $\beta \log \pi^*(a_t | s_t) = Q^*(s_t, a_t) - V^*(s_t)$

通过带入Q*之后并求和我们能得到
$\sum_{j=0}^{t} \left[ r(s_j, a_j) + V(s_{j+1}) - V(s_j) \right] = \beta\sum_{j=0}^tlog\frac{\pi _\theta(s_j|a_j)}{\pi_{ref}(s_j|a_j)}$

考虑到循环相消，所以最后只有$V(s_{t+1})$以及$V(s_0)$
基于以上内容我们定义一个Cumulative Process Reward:
$\mathcal{R}_t := \sum_{j=0}^{t} r(\mathbf{s}_j, \mathbf{a}_j) + V(\mathbf{s}_{t+1}) = V(\mathbf{s}_0) + \sum_{j=0}^{t} \beta \log \frac{\pi(\mathbf{a}_j | \mathbf{s}_j)}{\pi_{\text{ref}}(\mathbf{a}_j | \mathbf{s}_j)}$
之前累加的奖励+和下一时刻的预期回报 $\Leftrightarrow$ 初始状态的汇报+累积的等价的奖励回报
类似于PRIME $r_{\phi}(y) = \beta \log \left( \frac{\pi_{\phi}(y)}{\pi_{\text{ref}}(y)} \right)$ 其中y是token

### MSA: Masked Step Advantage

Start from the same prompt (initial step).
Masked if terminal before step t.

$$\text{MSA}_{i,t} = \mathcal{R}_{i,t} - \text{masked\_mean}(\{\mathcal{R}_{i,t}\}_i)$$
之前论文中已经定义好了process reward，这里开始考虑advantage。考虑到类似PRIME的方法，这里把t步之前的打包到一起看作单步的操作，然后纵向的考虑所有轨迹在第t步中的优势，也就是下图中竖着计算的线（类似Kimi 1.5中把所有Step打包到一起）。其中考虑到Cumulative Process Reward的定义式子的后半部分$ V(\mathbf{s}_0) + \sum_{j=0}^{t} \beta \log \frac{\pi(\mathbf{a}_j | \mathbf{s}_j)}{\pi_{\text{ref}}(\mathbf{a}_j | \mathbf{s}_j)}$, 那么这样计算出来的mean应该可以表达为$V(s_0)$再加一部分, 这么一减就消掉这一项。

如果我们直接使用以上类似的思路，但是去点KL divergence我们能够得到非常类似的内容。
For objective function: $$\max_{\pi} \mathbb{E}_{s_0 \sim \rho(s_0), a_t \sim \pi(a_t | s_t)} \left[ \sum_{t=0}^{T} r(s_t, a_t) + \beta \mathcal{H}(\pi) \right]$$

Optimal policy: $$\pi^*(a_t | s_t) = \frac{e^{Q^*(s_t, a_t) - V^*(s_t)}}{\beta}$$

For value function:  $$V^*(s_t) = \beta \log \sum_{a \in A} e^{Q^*(s_t, a_t) / \beta}$$

For non-terminal Q-function: $$Q^*(s_t, a_t) = r(s_t, a_t) + V^*(s_{t+1})$$
For terminal Q-function: $Q(s_t,a_t) = r(s_t,a_t)$ 

Corresponding bellman equation: $$r(s_t, a_t) + V^*(s_{t+1}) - V^*(s_t) = \beta \log \pi^*(a_t | s_t)$$

Compute the CPR:
$$R_t:=\sum_{j=0}^t r(s_j, a_j) + V(s_{t+1}) = V(s_0) + \sum _{j=0}^t\beta log\pi(a_j | s_j)$$

基于这个CPR我们能够同样的得到一个MSA$$\text{MSA}_{i,t} = \mathcal{R}_{i,t} - \text{masked\_mean}(\{\mathcal{R}_{i,t}\}_i)$$，并基于此进行运算。
